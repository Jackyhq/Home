## 个人内容边界

- `src/content/personal.ts` 独立存放个人身份、域名、SEO、联系方式、标语、个人介绍和头像描述；该模块只包含数据。
- `src/config/site.ts` 与 `src/i18n/` 组合个人数据、语言配置和通用界面文案。程序、组件、样式和同步逻辑仍属于代码授权范围。
- `src/data/` 中的照片数据、`src/assets/` 中的头像和个人网站图标保留权利；外链照片也不因链接出现在源码中而获得开源授权。
- 个人内容在测试或文档中重复出现时仍保留权利。仅允许为本项目的私人本地预览和测试复制随仓库提供的内容；发布另一个站点前须换成自己的素材、资料和配置。
- 第三方材料保持原许可，字体和图标的许可原文存于 [`public/licenses/`](../public/licenses/)，随两版静态产物一起提供。

这是一份可见内容的使用权利划分，不是保密机制。已确认保留现有网站展示；公开源码后，这些内容仍可被查看和下载。

## 用于自己的站点

替换个人资料、域名、统计 ID、邮箱、社交账号、备案号、头像、图标与相片数据。
相片同步与 schema 的 URL 校验目前针对作者的摄影档案，改用其他上游时也需要
更新对应的域名、路径规则和测试；仅修改首页展示链接不会改变数据校验契约。

发布修改后的程序时，按 AGPL 保留通知并提供适用的对应源码获取方式；第三方
字体与图标的通知随 `public/licenses/` 一起保留。素材授权和品牌使用仍按
[NOTICE.md](../NOTICE.md) 分别处理。
